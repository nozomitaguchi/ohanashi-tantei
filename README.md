# おはなし探偵
小学校１年生向けの文章題112問。ビルド不要の静的サイトです。

## 構成
112問を５段階に統合しています。以前の12問も文章の情報量と計算回数に応じた段階に含め、追加問題の後に配置しています。各段階は最大５問ずつのチャレンジに分かれます。
1. 10以内の数で１回の計算
2. 全体と一部・２つの数の比較
3. 20以内の数と、使わない情報
4. ２回の出来事
5. 足し算と引き算が混ざる出来事

何を求めるか → 式を組み立てる → 答えを選ぶ。正解時は２音のチャイムと説明ダイアログを表示します。

## GitHub Pages
mainブランチの / (root) を公開します。このフォルダ内のファイルとaudio・assetsフォルダを一緒に配置してください。
音声はGoogle AI Studioで生成したWAVです。公開サイトにAPIキーは不要です。未生成の問題では再生ボタンが無効になっています。
文章を変更するときは対応する音声も作り直してください。app.jsのnarratedQuestionsは音声がある問題の0始まりの番号です。
記録はブラウザのlocalStorageだけに保存します。

問題文を改訂した際は、古い音声を有効のままにせず、narratedQuestionsから外して再生成してください。

## 共有・ホーム画面
index.htmlに説明・OGP・Twitterカード・構造化データを設定しています。
assets/share.pngは1200×630の共有画像です。assets/apple-touch-icon.pngは180×180のiPad用アイコンです。
Safariの共有メニューから「ホーム画面に追加」でアイコンを追加できます。ネット接続が必要です。
